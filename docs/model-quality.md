# 降智检测（CUST-OBS-003）

2026-11-28 升级为本站网关自定义检测。管理员入口位于二开功能中的降智检测。默认关闭，升级后保留原分组和模型引用并暂停，补齐接口、题目和待测模型后保存启用。旧第三方客户端已经移除。

## 题库和请求配置

集中题库最多50题，每个分组最多20个模型配置，每个配置最多选择10题。题目包括名称、测试提示词、可选系统提示词、文本/SVG/HTML输出类型和判定规则。内置糖果逆推题与鹈鹕骑自行车SVG动画仅作为可编辑示例。

| 判定规则 | 行为 |
| --- | --- |
| 数字相等 | 去掉首尾空白，整段解析十进制数后精确比较，支持科学计数法；夹带解释或非数字为无法判定 |
| 字符串相等 | 只去掉首尾空白，区分大小写，不自动去围栏或提取子串 |
| 模型判题 | 生成结果先持久化，再把原题与输出作为JSON数据交给同一个待测模型；严格输出“通过”或“不通过”，其他为无法判定 |

只配置待测模型的本站分组、当前管理员自己的有效密钥、接口、模型名称、推理参数、输出上限和超时。模型判题复用待测模型的完整请求参数，只替换为判题提示词和待评作品；题库不再配置独立判题模型。每个任务分别冻结配置，同一道题用于不同模型时不会串用。只保存密钥引用，列表仅返回脱敏文本；生成和判题均消耗该密钥额度。作品判断依据源码，不声称已经运行或看到渲染。

| 接口 | 请求路径 | 推理参数 |
| --- | --- | --- |
| Chat Completions | /v1/chat/completions | reasoning_effort，可选thinking；输出上限字段可选max_completion_tokens或max_tokens |
| Responses | /v1/responses | reasoning.effort |
| Claude Messages | /v1/messages | thinking模式与预算、output_config.effort |
| Gemini | /v1beta/models/{model}:generateContent | thinkingLevel或thinkingBudget，两者择一 |

平台不决定协议，选择本站该模型实际支持的接口。推理强度留空时不发送；不同模型接受的参数以其网关接口为准，不替换模型或自动切换协议。高级JSON扩展参数不能覆盖模型、提示词、凭据、工具、流式、推理和输出上限等受管理字段。新建模型默认输出上限128000 tokens，单阶段超时1200秒，可设30～3600秒。后端对缺省值采用相同默认，已有明确配置保持不变。

API端点只读系统api_base_url，保留自定义路径，规范化末尾/v1，必须是公网HTTPS。请求禁止重定向，并在实际连接时核验和固定公网解析地址。检测不提供任意第三方URL或外部凭据入口。

## 调度、恢复与用量

全局最多两个模型调用，分组轮次不重叠。分组间隔5～1440分钟，默认60分钟，从上一轮完成时间安排。配置行锁、任务租约和持久化阶段使多实例共享上限。每次外部调用都计入生命周期后台工作，蓝绿排空会等待它完成。

生成与判题分别保存正文、结束原因、状态、开始时间、耗时、请求ID和接口返回的用量；汇总包含历史重判。超时区分等待响应头和接收正文两个阶段。网关会重新生成计费关联ID，因此收到响应头后保存X-Client-Request-Id响应值用于关联日志；未收到响应头时仅保留发出标识用于诊断，不据此推断账号。升级前缺少网关实际标识的记录可能显示“未记录”。截断、拒答、空输出、网络错误和超时不直接判为降智。调用结果不明确时不自动重发，失联占位保留到完整请求超时及存档余量结束。仅网关明确拒绝受理的限流允许有限重试。

生成完成后，即使判题失败也保留作品。管理员可仅重新判题，最多追加3次，不重新生成、不覆盖历史判题。使用该记录冻结的判题配置和原文；原密钥失效需重新发起检测。修改当前配置不会改写历史请求参数。升级前已经创建的任务继续使用历史冻结配置，包括原先独立配置的判题模型；新建任务统一复用待测模型。保留内部judge快照字段以兼容历史任务和共存旧实例，配置接口会清除并忽略旧客户端提交的独立judge。关闭检测后取消排队和后续阶段，正在处理的阶段允许存档；隐藏用户入口。

## 结果与隔离

登录用户查看所选分组最近24小时记录。画廊动态展示题目与结果，详情显示每题源码/回答、生成与判题用量及历史判题。答案标题明确标注题名；默认选中已有答案的题目，保留用户手动选择，等待生成和无有效回答分开展示。执行阶段未开始或进行中不再以0秒表示。设置页采用分组/题库导航和集中编辑，模型参数可折叠，高级参数收起；使用应用的正常布局、字体和主题色。新版ID为v2-UUID，旧版为v1-数字；旧数字链接继续可用，联合分页遵守相同权限和保留期。

沿用两层sandbox及独立CSP作品预览，正文只以文本展示。共享加载器保留合并请求、最多四路预加载、24条/约32MiB缓存，以及过期、退出、换号、关闭、权限失效清理。密钥、请求快照和服务端调用凭据不出现在用户结果中。

独立SVG及只有一个SVG主画布的嵌套容器按完整viewBox等比居中适配画廊、详情和全屏。没有viewBox但具有有效宽高时补齐画布坐标；保留作品内部动画，不需要滚动查看完整画布。普通HTML/Canvas仍保留原布局，沙箱权限不变。

命中账号是私有扩展：仅生产已核验的saviour2411管理员（固定用户ID 1，数据库再次核验管理员角色、启用状态、未删除及邮箱前缀）可获得account_hits。其他用户、同名普通用户及其他管理员的列表和详情接口完全不返回账号字段，也不执行账号关联查询。生成、判题、历史重判分别按阶段请求ID关联实际用量或最后错误记录，同时匹配冻结配置中的密钥、用户及分组；缺少证据显示“未记录”，不根据时间或模型猜测。管理员详情定时刷新迟到的关联；身份、角色和邮箱变化会清理缓存。账号信息不传入作品沙箱。
