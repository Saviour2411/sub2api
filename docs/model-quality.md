# 降智检测（CUST-OBS-003）

设计于 2026-10-15 获得确认。正式入口位于“渠道状态”下方，管理员配置位于“二开功能 → 网关配置 → 降智检测 → 每日签到”。默认关闭，开启后所有登录用户可以查看已选 OpenAI 分组最近 24 小时的结果，不影响分组启停、路由或请求计费规则。

## 配置

- 每组选择当前管理员已有的对应分组有效密钥；下拉框仅返回名称、ID 和脱敏文本，配置仅保存密钥引用。允许暂不绑定，此时暂停该组检测。
- API 端点读取系统 `api_base_url`，规范化末尾 `/v1`，要求公网 HTTPS；域名解析失败或解析出内网地址时暂停。保留自定义路径。
- 检测间隔 5～1440 分钟，默认 60；默认同时执行糖果和鹈鹕测试。模型去重后至少一个，最多 20 个；最多配置 50 个分组。每次显式传入模型及 `low / medium / high` 推理程度，默认 `low`，不指定快速服务档位。满血AI统一使用 Responses 协议，不再发送已移除的 `protocol` 参数。
- 2026-10-17 核验的满血AI接口仅允许 `gpt-6-astra` 执行鹈鹕检测，其他模型可使用糖果检测。保留管理员选择的模型，第三方拒绝时显示对应限制，不替换模型或把请求失败判为降智。
- 测试会向满血AI提交绑定密钥，并消耗该密钥的额度。管理员可立即检测，同组已有轮次时返回冲突。修改配置后先保存再立即检测。

## 调度与恢复

满血AI使用 `POST /api/v1/tests` 创建任务、`GET /api/v1/tests/{id}` 查询结果。服务每 3 秒推进任务，每 30 秒检查新轮次；复用共享后台任务准入、PostgreSQL advisory lock 及应用停机机制。数据库配置行锁保护全局两个并发槽，活动轮次唯一索引保护同组不重叠；下一轮从上一轮全部结束后计算，不补跑停机期间的历史时间点。

任务先保存稳定幂等键与提交状态，再调用第三方。取得任务 ID 后持久化并恢复轮询。第三方幂等范围包含客户端 IP，无法保证跨实例出口一致，因此网络中断或提交结果不明时不盲目重发；异常任务保留槽位至 11 分钟安全等待期结束。429/503 的明确拒绝遵循 `Retry-After`、指数退避和抖动，最多提交 5 次；排队超过 1 小时结束该项。第三方任务过期、超时、网络故障只记失败，不判为降智。

关闭功能后停止新提交并取消未提交任务，继续查询已提交任务；原配置中的密钥失效或分组停用不会阻止管理员关闭功能。配置保存与轮次创建使用版本校验，启用及修改绑定时核验当前管理员的密钥，执行前重新核验密钥所属管理员、有效期、状态、额度及分组绑定。糖果和鹈鹕的执行状态、答案、作品与判定分别存储。单项失败不覆盖另一项；整体结果优先展示检测中、疑似降智、失败、无法判定、正常，具体原因查看详情。

提交被明确拒绝时记录 HTTP 状态码。对于 HTTP 400，仅将已知的参数不兼容和模型限制映射为固定中文提示；未知、损坏或超过 4 KiB 的错误响应仍使用通用提示，不持久化或透出原始错误正文。

## 存储与隔离

迁移 `246_model_quality.sql` 新增配置、轮次、计划、模型记录和独立任务表，不修改旧迁移。用户列表仅加载摘要，每页 12 条，按开始时间及 ID 倒序；详情才读取完整 HTML 和答案。结果按开始时间保留 24 小时，查询直接排除过期数据，后台每分钟清理并级联删除记录及作品，功能关闭后仍执行。历史清理后仍保留下次检测时间。

用户接口不返回密钥引用、第三方 ID、内部端点和原始错误。糖果答案与判定原因脱敏并按纯文本展示。作品由父页面完成鉴权后，通过 `postMessage` 传入两层空白预览壳；预览壳本身不提供数据或访问凭据。独立 CSP 和 sandbox 允许动画脚本，禁用同源权限、连接、外部资源、工作线程、弹窗、表单和顶层跳转；外层 `frame-src 'self'` 同时约束作品自身向外站导航。不放宽主站 CSP。作品进入视口才加载，离屏、页面隐藏或打开详情时卸载画廊中的动画。

## 接口

所有接口使用 `/api/v1` 前缀。管理员配置读写为 `/admin/custom-features/model-quality`；密钥选择为 `/admin/custom-features/model-quality/keys?group_id=...`；立即检测为 `POST /admin/model-quality/groups/:id/run`。登录用户读取 `/model-quality/groups`、`/model-quality/runs` 和 `/model-quality/runs/:id`。列表参数为 `group_id`、`model`、`method`、`outcome`、`page`。

空白隔离壳 `/model-quality/preview` 与 `/model-quality/artwork` 不需要登录，不包含任何检测结果。关闭功能后用户数据接口返回 404。

## 验证与发布

自动测试通过模拟第三方验证请求参数、退避、异常提交、重启轮询、关闭行为、密钥校验和独立结果。设置 `MODEL_QUALITY_TEST_DSN` 可在专用 PostgreSQL 中执行并发抢占、迁移幂等、分页、结果保存及清理测试；测试使用独立随机 schema，结束后移除。不得将该变量指向生产库。

CI 的后端集成步骤提供独立 PostgreSQL 服务并执行该数据库测试；画廊、配置、预览、功能开关和管理路由用例纳入前端关键测试清单。

浏览器验收使用正式 Vue 页面与真实预览处理器输出，配合本地示例数据验证桌面、手机、动画及恶意 HTML 隔离。真实检测调用由配置完成后的管理员“立即检测”执行；本轮不进行生产部署。
