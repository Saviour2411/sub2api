# 降智检测（CUST-OBS-003）

2026-11-28 升级为本站网关自定义检测。管理员入口位于二开功能中的降智检测。默认关闭，升级后保留原分组和模型引用并暂停，补齐接口、题目和判题模型后保存启用。旧第三方客户端已经移除。

## 题库和请求配置

集中题库最多50题，每个分组最多20个模型配置，每个配置最多选择10题。题目包括名称、测试提示词、可选系统提示词、文本/SVG/HTML输出类型和判定规则。内置糖果逆推题与鹈鹕骑自行车SVG动画仅作为可编辑示例。

| 判定规则 | 行为 |
| --- | --- |
| 数字相等 | 去掉首尾空白，整段解析十进制数后精确比较，支持科学计数法；夹带解释或非数字为无法判定 |
| 字符串相等 | 只去掉首尾空白，区分大小写，不自动去围栏或提取子串 |
| 模型判题 | 生成结果先持久化，再把原题与输出作为JSON数据交给独立判题模型；严格输出“通过”或“不通过”，其他为无法判定 |

被测模型和判题模型分别选择本站分组、当前管理员自己的有效密钥、接口、模型名称、推理参数、输出上限和超时。只保存密钥引用，列表仅返回脱敏文本。判题同样消耗其绑定密钥额度；作品判断依据源码，不声称已经运行或看到渲染。

| 接口 | 请求路径 | 推理参数 |
| --- | --- | --- |
| Chat Completions | /v1/chat/completions | reasoning_effort，可选thinking；输出上限字段可选max_completion_tokens或max_tokens |
| Responses | /v1/responses | reasoning.effort |
| Claude Messages | /v1/messages | thinking模式与预算、output_config.effort |
| Gemini | /v1beta/models/{model}:generateContent | thinkingLevel或thinkingBudget，两者择一 |

平台不决定协议，选择本站该模型实际支持的接口。推理强度留空时不发送；不同模型接受的参数以其网关接口为准，不替换模型或自动切换协议。高级JSON扩展参数不能覆盖模型、提示词、凭据、工具、流式、推理和输出上限等受管理字段。默认输出上限8192 tokens，单阶段超时600秒，可设30～3600秒。

API端点只读系统api_base_url，保留自定义路径，规范化末尾/v1，必须是公网HTTPS。请求禁止重定向，并在实际连接时核验和固定公网解析地址。检测不提供任意第三方URL或外部凭据入口。

## 调度、恢复与用量

全局最多两个模型调用，分组轮次不重叠。分组间隔5～1440分钟，默认60分钟，从上一轮完成时间安排。配置行锁、任务租约和持久化阶段使多实例共享上限。每次外部调用都计入生命周期后台工作，蓝绿排空会等待它完成。

生成与判题分别保存正文、结束原因、状态、耗时和接口返回的用量；汇总包含历史重判。截断、拒答、空输出、网络错误和超时不直接判为降智。调用结果不明确时不自动重发，失联占位保留到完整请求超时及存档余量结束。仅网关明确拒绝受理的限流允许有限重试。

生成完成后，即使判题失败也保留作品。管理员可仅重新判题，最多追加3次，不重新生成、不覆盖历史判题。使用该记录冻结的判题配置和原文；原密钥失效需重新发起检测。修改当前配置不会改写历史请求参数。关闭检测后取消排队和后续阶段，正在处理的阶段允许存档；隐藏用户入口。
