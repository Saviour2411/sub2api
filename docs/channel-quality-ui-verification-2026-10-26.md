## 功能与浏览器检查

- 渠道按既有平台顺序分区，区内保留输入顺序，未知平台追加，Image 独立。普通卡片约 146px，1600px 四列、2213px 六列；配额或较长内容可增加卡片高度。列表没有最后检测/成功时间、检测次数及重复倒计时，保留顶部刷新、历史条、周期、分组和配额显示规则。
- 明确区分数据过期、暂无样本与真实 0% 成功率；过期记录不泄露旧延迟或配额。
- 画廊在 390px 两列、1600px 四列、2213px 六列；320px 退为一列。320/390/768/1600/2213px 均无横向溢出，桌面和手机均检查深浅主题。深色卡片背景和平台标题另外核验浏览器计算样式，避免只检查主题类名。
- 列表不展示完整答案及原因；详情答案中包含的 `<script>` 按纯文本显示，不形成脚本节点。复制、作品全屏、直接打开详情、查询参数、筛选分页和返回滚动位置均实际操作验证。
- 同内容刷新不重建 iframe；滚出后卸载、重新进入恢复动画。后台场景在真实 Chrome 中切换 `document.hidden` 并触发可见性事件，验证卸载与恢复；没有将该模拟声称为操作系统窗口最小化测试。
- 使用现有 Go 预览处理器中的脚本及同一组 CSP、sandbox 和响应头生成本地预览响应。浏览器实际执行作品动画，并验证无法读取父窗口 DOM、登录存储或发起网络请求。检查两次作品截图的像素差异，确认可见且仍在运动。
- 功能关闭清除作品实例；独立详情的未登录及功能关闭访问分别被既有守卫拦截。最终页面没有未处理脚本异常。

## 加载测量

采用实际 Vue 应用和 Chrome，基线源码单独导出到工作区内。两个版本使用相同的 12 条列表记录、相同已保存的 HTML 动画和固定 180ms 正文接口延迟；预览壳沿用现有隔离策略。先预热开发服务，随后各执行三轮。视口为 1600×600，顺序为首次进入、滚出首条记录、滚回、打开详情、返回画廊。时间包含实际滚动、界面呈现及浏览器等待，属于本地受控端到端测量，不代表生产网络或真实供应商吞吐。

## 发现与修复

| 问题或失败 | 修复与影响 |
| --- | --- |
| 默认 pnpm 触发自动重装，因无 TTY 中止 | 使用原有 pnpm 9.15.9 和冻结锁文件完成安装；属于本机工具链差异 |
| 滚动快照可选字段与恢复函数类型不一致 | 恢复函数接受可选锚点；类型检查通过 |
| 超长到期时间超过浏览器定时器上限 | 分段检查到期时间；2099 年测试期限不再立即失效 |
| 切换详情后旧请求的 `finally` 可能影响新请求锁 | 以请求代次校验收尾，仅当前请求更新状态 |
| 同账号资料刷新重新创建用户对象时误清缓存 | 分别监听账号 ID 与登录状态，只有值实际变化才清理 |
| 返回列表时全站平滑滚动与后台刷新竞争 | 使用立即恢复，实际浏览器返回 180px 的原位置；增加断言 |
| 手机分组下拉框文字被既有内边距压缩 | 明确高度、行高、内边距，实测手机文字完整 |
| 渠道深色样式编译后只剩 `.dark` | 将完整选择器置于 `:global(...)`，修复普通卡片、平台标题和 Image 卡片；实际计算颜色与截图复验 |
| 新测试的 iframe 未挂载到文档、使用了当前 Vitest 不支持的断言 | 挂载到文档并采用兼容断言；属于测试夹具问题 |
| 首次全量测试 3203 个断言通过，但有两项测试结束后的动画异常 | 既有 `KeyUsageView` 测试改用可清理定时器；最终 3204 个用例及进程退出均通过，未修改余额页产品行为 |
| 浏览器验收初期的环境和计数问题 | 补齐基线导出的 `docs/legal` 依赖；登录初始化仅作用于顶层页面；按 URL pathname 统计带查询参数的请求；渠道使用真实 `/monitor` 路由；等待侧栏断点及全屏过渡稳定后检查。无效结果未计入最终测量 |
| 后台启动辅助服务命令被自动审批策略拒绝 | 改用工具管理的前台执行会话启动本地接口与 Vite；未访问远程服务器 |
