## 已知内存风险

Go 的 80% 是软内存限制，不是预分配或进程硬限制。它与 PostgreSQL 25% 固定共享缓存的预算合计已超过物理内存，尚未计入 PostgreSQL 私有内存、Redis、Nginx、系统和其他应用；极端负载仍有 OOM 风险。已在执行前向用户说明，按用户明确指定比例落地，不将这些参数描述为经过峰值压测的安全容量。

`effective_cache_size` 只是规划器估值，不实际预留对应内存。容器 `/dev/shm` 与 `shared_buffers` 分别控制不同共享内存用途。
