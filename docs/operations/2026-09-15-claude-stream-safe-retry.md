| 配置字段 | 默认 | 允许范围 |
| --- | --- | --- |
| anthropic_stream_safe_retry_enabled | false | 布尔值 |
| anthropic_stream_safe_retry_max_retries | 2 | 整数0–5；0不重发 |
| anthropic_stream_safe_retry_total_wait_seconds | 300 | 整数1–600秒 |

沿用现有 /admin/custom-features/gateway 接口及 settings 存储，无数据库迁移。旧客户端不提交新字段时保留现值；保存后复用运行时缓存失效，多实例仍遵循原缓存TTL。在途请求不重新读取这些设置。关闭后恢复既有流处理与重试规则，但完整终止事件校验保留。

## 安全边界

- 预算在首次成功流响应头返回时启动。首次响应头等待仍受既有配置约束，并非新功能承诺整请求300秒内结束。预算开始后，重试中的选号、排队、500毫秒退避、响应头和流等待均消耗同一预算，不允许账号10次配置放大它。
- 默认最多额外2次，不保证能够发完3次上游请求。例如首次空闲180秒、第二次等待到累计300秒，就直接终止；不会给第三次重置时间。预算比流空闲超时更短时，可能完全没有恢复机会。
- 先重试原账号一次，再换其他正常账号。没有替代账号时，允许仍可调度且允许同号重试的原账号使用剩余次数。保留账号重试为0、不可重放错误、首 Token 直接换号、既有最大换号数及所有调度资格，不启用停调度账号。
- 缓存仅容纳明确无生成内容的前导帧及待判定完整事件，累计上限256 KiB；不与首 Token 守卫重复缓存。收到文本、思考、工具调用或未知事件后，在写出前关闭重放资格；写失败也不再生成。未知事件不能被猜测为可丢弃心跳。
- 完整 message_stop 或兼容 [DONE] 必须包含事件分隔空行，完整转发并刷新后返回并关闭上游响应体；事件名孤行、半帧和无终止的 EOF 不能伪装成功。协议错误、上游业务错误、缓存超限及不可重放标记不通过重试隐藏。
- 内容交付后解除新等待预算，但保留原流空闲超时。指定分组首 Token 保护仍不把纯空白当作有效输出；即使已经交付纯空白，也不能在同条流重放。客户端取消时不启动新尝试；已交付后保持既有排空与部分用量语义，排空仍受原流空闲配置约束。
- 未提交响应时返回明确 HTTP 错误；已提交时写出既有格式的完整 SSE error 帧后正常完成响应。不拼接第二条消息、不补造 message_stop、不主动关闭可复用 TCP 连接。

## 用量与可观测性

失败后仍重试的尝试不单独向客户扣费。成功只提交最终结果；最终失败优先取最终尝试计量，没有则取最近有计量尝试及其原账号，不把多次失败用量相加。保持原请求去重键、按用户串行扣费、5秒 usage task 上限。新增快照不改变 UpstreamFailoverError 对外 result=nil 的约定。

提供请求ID、上游请求ID、分组和账号、尝试序号、最后事件类型、完整终止／内容提交状态、前导字节、心跳数、上游最近读取间隔、首语义输出时间、累计时间、剩余预算和次数、用量摘要、重试／停止原因及恢复结果。日志不新增请求正文、生成正文、思考、工具参数或凭据。未知事件名归一为固定类别。

诊断复用现有 Ops 事件JSON、事件数量与字节限额，入队复制快照，错误详情单独展示。实际上游HTTP200与本地逻辑502／504分开保存；恢复成功的尝试故障不能算作最终客户失败。普通流错误不转成账号HTTP状态码封禁，保留既有流超时与首Token策略。

重试无法保证 provider 不会对第一次失败请求收费；本功能承诺的是可控恢复、无客户流拼接和不重复提交客户用量，而非消除上游重复成本。此版本不降低原180秒空闲阈值，不修改生产3600秒响应头超时、资源参数或任何账号。
